# ❤️ 微信每日早安推送程序（送给女朋友的专属仪式感）

每天早晨自动给女朋友（以及你自己）发送一条温馨浪漫的微信早安问候！
支持包含：**当天天气、气温贴士、恋爱天数、生日倒计时、每日情话/金句**。

无需购买云服务器，借助 **GitHub Actions** 每天免费自动定时推送。

---

## 🛠️ 第一步：申请微信测试号（3分钟搞定）

因为微信正式服务号需要企业认证，个人可以使用微信官方提供的**免费免审核测试号**。

1. **登录微信测试平台**：
   访问微信公众平台测试账号页面：[https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login](https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login)
   用你的微信扫码登录即可。

2. **获取核心凭证**：
   - 页面顶部可以看到：`appID` 和 `appsecret`。

3. **扫码关注与获取 OpenID**：
   - 页面向下滚动，会看到一个“**测试号二维码**”。
   - 拿你自己的微信以及**女朋友的微信**扫码关注该测试号。
   - 扫码关注后，右侧的“用户列表”里就会出现对应的“微信号”（这就是 `User OpenID`，一串字符）。

4. **新增消息模板**：
   在页面中找到“**新增测试模板**”，点击新增：
   - **模板标题**：`早安宝贝`
   - **模板内容**（直接完整复制下面这段文本粘贴进去）：

```text
亲爱的宝贝，早安！❤️

📅 今天是：{{date.DATA}}
🏙️ 城市：{{city.DATA}}
⛅ 天气：{{weather.DATA}}
🌡️ 气温：{{temperature.DATA}}
💨 风力：{{wind.DATA}}
💡 贴士：{{tips.DATA}}

👩‍❤️‍👨 我们已经相恋了：{{love_days.DATA}}
🎂 距离你的生日：{{birthday_days.DATA}}

{{words.DATA}}
```

   - 点击提交后，会生成一个 **模板ID (`template_id`)**。

## 💻 第二步：本地一键测试（即时验证）

在上传 GitHub 之前，可以在本地电脑先测一次，确认手机能正常收到消息：

1. 复制一份配置文件：
   将项目根目录的 `config.example.json` 复制并重命名为 `config.json`。

2. 填入你的真实信息：
```json
{
  "app_id": "你的微信测试号appID",
  "app_secret": "你的微信测试号appsecret",
  "template_id": "刚才生成的模板ID",
  "user_openid": "女朋友扫码后获取的openid,你自己的openid",
  "city": "北京",
  "start_date": "2023-05-20",
  "birthday": "10-01",
  "custom_note": "今天又是超级想你的一天，记得按时吃早饭哦！"
}
```
> 💡 提示：`user_openid` 可以填多个，用半角逗号 `,` 隔开，这样你和女朋友能同时收到推送。`config.json` 已在 `.gitignore` 中，不会被意外推送到公共代码库。

3. 运行测试：
```bash
python main.py
```
运行后，手机微信就会立刻收到一条精美的早安卡片！

## ☁️ 第三步：配置 GitHub Actions（免服务器每天定时自动推送）

想让它每天早晨（例如 7:30）全自动推送，只需将本仓库推送到你的 GitHub：

1. 将代码提交并推送到你个人的 GitHub 私有/公开仓库。
2. 进入仓库页面的 **Settings** -> **Secrets and variables** -> **Actions**。
3. 点击 **New repository secret**，依次添加以下环境变量：

| Secret 变量名 | 说明 | 示例值 |
| :--- | :--- | :--- |
| `APP_ID` | 微信测试号 appID | `wx123456789...` |
| `APP_SECRET` | 微信测试号 appsecret | `abcdef123456...` |
| `TEMPLATE_ID` | 消息模板 ID | `k9_aBcDeF...` |
| `USER_OPENID` | 接收消息的 OpenID（多个用逗号隔开） | `oABC123...,oXYZ456...` |
| `CITY` | 女朋友所在城市名称 | `北京` 或 `上海` |
| `START_DATE` | 恋爱纪念日（格式：年-月-日） | `2023-05-20` |
| `BIRTHDAY` | 女朋友生日（格式：月-日） | `10-01` |
| `CUSTOM_NOTE` | 你想额外嘱咐的甜言蜜语（选填） | `记得喝温水哦！` |

4. **开启与测试定时任务**：
   - 点击仓库顶部的 **Actions** 标签页。
   - 在左侧选择 **微信每日早安推送** 工作流。
   - 点击右侧的 **Run workflow** 按钮手动触发一次，验证 GitHub Actions 是否正常发送。
   - 以后每天北京时间早晨 **07:30**，GitHub 就会自动唤醒并替你准时送出这份早安心意！

## 🌸 小亚晴专属浪漫小站（GitHub Pages）

位于 `gift/index.html`，无需买服务器，免费部署成专属网页：
* **实时秒级恋爱计时器**：天、时、分、秒动态跳动（起始日：2022-05-05）。
* **唯美设计**：柔粉渐变背景、Canvas 细腻樱花飘落粒子特效、轻拟态毛玻璃质感。
* **暖心功能**：写给小亚晴的专属手写情书、浪漫心动签抽取盲盒、独家记忆时间线。
* **背景轻音乐**：右上角唱片图标，轻触即可播放浪漫钢琴曲。
* **微信直接跳转**：在 `config.json` 或 GitHub Secrets 配置 `TARGET_URL`（即你的 GitHub Pages 链接），微信卡片轻轻一点直接全屏沉浸式打开！

### 🚀 如何开启 GitHub Pages 专属链接：
1. 代码推送到你的 GitHub 仓库后，进入仓库页面的 **Settings** -> **Pages**。
2. 在 **Branch** 处选择 `main`（或 `master`），目录选择 `/ (root)`，点击 **Save**。
3. 稍等 1~2 分钟，页面上方会生成一个链接：`https://<你的用户名>.github.io/<仓库名>/gift/`。
4. 将这个链接填入 GitHub Secrets 的 `TARGET_URL`（本地测试填到 `config.json` 的 `target_url`），微信早安推送就会带上跳转入口！

## 🎁 进阶小心意：晚安推送 · 节日惊喜 · 纪念日彩蛋

> 灵感参考 GitHub 开源项目 `wechat-public-account-push` 等，农历换算使用开源库 [6tail/lunar-python](https://github.com/6tail/lunar-python)。

> [!IMPORTANT]
> 微信模板消息（2023 年新规后）**每个字段最多显示 20 个字、不支持换行、不支持自定义颜色**，模板第一行也不会显示。程序已把所有文案控制在 20 字以内，你自己新增文案时也请遵守这个规则（超出会被自动裁剪并在日志提醒）。

### 💬 文案库 `messages.json`

早安心意、早安情话、晚安叮嘱、晚安情话四组文案都在这里，每天按顺序轮换、一轮内不重复。想加你们之间的专属梗，直接往里加就行（每句 ≤ 20 字，不用加表情）。

### 🌙 每晚晚安推送（22:00）

- 工作流文件：`.github/workflows/night_push.yml`，每天北京时间 **22:00** 自动发送。
- 内容：**明天的天气 + 带伞/加衣提醒**、相恋天数、一句晚安叮嘱、一句晚安情话。
- 因为模板标题是写死的（早安模板叫“早上好~小亚晴”），晚安需要**单独新建一个模板**，标题如 `晚安~小亚晴`，内容：

```text
🌙  {{weather.DATA}}
☂️  {{tips.DATA}}
❤️  {{love.DATA}}
💤  {{note.DATA}}
✨  {{quote.DATA}}
```

  把生成的模板 ID 填到 `config.json` 的 `night_template_id` 和 GitHub Secret `NIGHT_TEMPLATE_ID`。未配置时晚安推送不会发送。
- 明天是特殊日子时，晚安贴士会提前预告：“明天是七夕，早点睡哦”。

### 🎉 自动识别的特殊日子（无需任何配置）

| 类型 | 举例 | 早安会变成 |
| :--- | :--- | :--- |
| 🎂 生日 | 04-04（支持农历） | 生日快乐！今天全世界都爱你 |
| 💍 恋爱周年 | 每年 05-05 | N周年快乐，往后每一年都是你 |
| 🌷 每月纪念 | 每月 5 号 | 在一起第N个月啦，每月都纪念 |
| 🎉 天数里程碑 | 每 100 天、520、1314、1666… | 相恋第1666天，顺顺利利 |
| 🌹 阳历节日 | 元旦、情人节、女神节、520、儿童节、万圣节、平安夜、圣诞、跨年… | 节日专属心意 |
| 🧧 农历节日 | 除夕、春节、元宵、端午、七夕、中秋、重阳、腊八 | 节日专属心意 |
| 🍃 二十四节气 | 立冬、冬至、立春… | 贴士换成节气关怀（下雨天优先提醒带伞） |

重要节日（情人节、七夕、圣诞、周年等）还会**提前 3 天**在早安里预告：“再过2天就是平安夜啦，期待吗”。

### 💌 自定义彩蛋日历 `surprises.json`

提前写好某天想对她说的话，到那天会自动替换“心意”这一行（每句 ≤ 20 字）：

```json
{
  "dates": {
    "2026-12-31": "这句话是我一个月前写好的",
    "09-15": {
      "name": "初次约会纪念日",
      "note": "还记得我们第一次约会吗",
      "night_note": "那天的晚风，我一直都记得",
      "major": true
    }
  }
}
```

- `YYYY-MM-DD` 只触发一次，`MM-DD` 每年都触发。
- 优先级：生日 > 周年 > 自定义彩蛋 > 节日 > 天数里程碑 > 每月纪念。
